# PatchVerdict

Evidence-first candidate repairs for public GitHub issues. The strict JS/TS flow
pins a selected branch and exact SHA, freezes an issue-specific reproduction,
compares unrelated test failures, and enforces one production-file repair.
AI proposes; deterministic checks decide; humans approve publication.

Read [setup and web usage](apps/web/README.md), the
[third-party flow, limits, and smoke checklist](docs/THIRD_PARTY_JS_TS_FLOW.md),
and the [architecture decisions](docs/THIRD_PARTY_JS_TS_ARCHITECTURE.md).
