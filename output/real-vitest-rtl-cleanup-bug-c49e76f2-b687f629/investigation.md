# Investigation Report

The DarkMode tests fail because rendered DOM elements from previous tests remain mounted in the document, causing query failures. The test file `src/components/DarkMode.test.tsx` imports `cleanup` from `@testing-library/react` but never calls it, and lacks an `afterEach(cleanup)` hook. Additionally, the `vi.mock` of `useDarkModeContext` is never reset, so mock return values persist across tests. This leads to DOM pollution (multiple 'light'/'dark' nodes visible in the body in the baseline failure output) and incorrect mock behavior. The root cause is insufficient test teardown, both for DOM cleanup and mock state reset.
