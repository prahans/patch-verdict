# Investigation Report

The DarkMode tests fail because the DOM from previous test suites remains mounted. Inspection of test files revealed that DarkMode.test.tsx uses renderWithContext, which wraps the component in DarkModeContextProvider but does not clean up after each test. The default test setup does not include automatic cleanup (e.g., vitest.setup.ts lacks `afterEach(cleanup)` or equivalent). The test-utils.tsx renderWithContext uses @testing-library/react's render without manual cleanup. In contrast, Counter.test.tsx does not rely on context wrapping and appears to pass. The authoritative baseline shows multiple mounted <div> elements in the body across test runs, indicating lack of DOM cleanup. The root cause is missing test cleanup between test cases, causing components and DOM nodes to accumulate. The recommended patch target is vitest.setup.ts to add automatic cleanup after each test.
