# Investigation Report

The investigation identified that importing 'node:stream/web' from jest.setup.js causes a crash in Jest 30 when using the jest-environment-jsdom environment. The authoritative baseline shows a TypeError: 'Value of "this" must be of type ReadableStreamDefaultReader' occurring during RequireCoreModule when protectProperties tries to copy core module properties. The error originates in Node's internal webstreams implementation, indicating that the jsdom environment does not properly initialize or support Node.js core stream web APIs. jest.setup.js directly imports the problematic module, and jest.config.js selects the incompatible environment (jest-environment-jsdom). The root cause is an environment mismatch: Node.js core streams APIs are not fully compatible with JSDOM's environment, especially during early initialization. The recommended patch target is jest.setup.js, where the incompatible import should be removed or guarded.
